Telegram file-to-link bot powered by ZerogramJS (MTProto) and JsonFlux. Forward any file, get download/watch/share links. Single-page WebApp with admin panel, moderation, i18n, quotas and live updates via Socket.IO. No 50MB limit, no external database.

File2LinkZeroJS v0.1.0

ZeroGramJS Telegram bot + React WebApp para convertir archivos compartidos en Telegram en enlaces descargables.

Features

  • ZeroGramJS: client auto-healing, reconnection, telegramAuth
  • JsonFlux: reactive JSON database with dirty tracking
  • File deduplication by hash + size
  • Language auto-detection (accept-language header)
  • Device routing: IOS -> iOS app instructions, TELEGRAM -> internal endpoint, DESKTOP -> direct
  • Admin panel: users, storage, moderation, settings, language per-user
  • File TTL auto-cleanup with configurable expiration
  • Real-time stats via polling
  • Full i18n support (en, es with language template)
