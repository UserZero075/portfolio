🚀 ZerogramJS v2.3.0

🟦 Migración a TypeScript & Arquitectura Dual

  • Tipado estricto integral: Código fuente 100% migrado a TypeScript (src/) con definiciones completas (.d.ts), mapas de código (.map) y build optimizado en dist/.
  • Compatibilidad dual ESM & CJS: Soporte para import Zerogram from 'zerogramjs' y const Zerogram = require('zerogramjs').
  • Shims retrocompatibles: Mantenidas las rutas heredadas (lib/*, shared/*, utils/*) redirigiendo a la compilación TypeScript para evitar breaking changes.

⚡ Rendimiento & Enrutamiento Avanzado

  • Throughput ultra alto: Router de eventos optimizado capaz de despachar +21,000 actualizaciones por segundo en pruebas de estrés.
  • Comandos en grupos con mención: Soporte nativo para sintaxis /command@BotName, filtrando comandos dirigidos a otros bots.
  • Alias de comandos: Registro de múltiples alias en un solo handler (bot.command(['start', 'inicio'], handler)).
  • Expresiones regulares (bot.hears): Detección de patrones textuales mediante RegExp con captura de grupos en ctx.match.
  • Callbacks con Regex: Soporte para patrones RegExp y prefijos estructurados (action:payload / action_payload) en bot.onCallback.
  • Middleware en modelo cebolla: Pipeline robusto tipo Koa/Express con protección contra múltiples llamadas a next().

🛡️ Seguridad, Sesiones Atómicas & Anti-FloodWait

  • Persistencia atómica de sesión: FileSessionManager utiliza escritura temporal y renombrado atómico POSIX (fs.rename), garantizando cero corrupción ante caídas.
  • Permisos restrictivos POSIX: Creación de carpetas de sesión con 0o700 y archivos con 0o600, más sanitización contra *path traversal*.
  • Proveedor de sesión desacoplado: Interfaz SessionStorage con implementación MemorySessionStorage para testing o serverless.
  • Rate Limiter integrado: Cola token-bucket con límites global (30 req/s) y por chat (1 req/s) para evitar bloqueos MTProto.
  • Reintento automático ante FloodWait: Detección de errores FLOOD / FLOOD_WAIT_X con espera inteligente y backoff configurable (autoFloodWait, maxFloodWait).

🎨 Formateo Markdown & HTML Seguro

  • Sanitización estricta: Escapado automático de entidades HTML (<, >, &) en texto libre sin romper etiquetas permitidas (<pre>, <code>, <tg-spoiler>, <a>, <b>, <i>, <s>), eliminando caídas por errores de parseo en Telegram.

📥 Descargas y Streaming Resiliente

  • Streams no bloqueantes con contrapresión: downloadMediaStream y downloadStream con control de drain y descarte inmediato ante desconexión o cancelación por señal.
  • Soporte HTTP Range (Seeking): Compatibilidad con rangos de bytes { start, end } con big-integer.
  • Descargas en lote concurrentes: downloadMediaBatch con worker pool y progreso acumulado.
  • safeEdit inteligente: Supresión transparente del error MESSAGE_NOT_MODIFIED en barras de progreso.

🧪 Suite de Calidad & Benchmarks

  • 33 tests automatizados con el runner nativo node:test y tsx (npm test).
  • Suite de impacto y estrés continuo (npm run test:stress): 10,000 updates en <500 ms, 1,000 callbacks en ráfaga paralela y 0 fugas de descriptores.
